import os
import json
from datetime import datetime

def parse_dialog(text):
messages = []
for line in text.split('\n'):
if line.startswith('Я:') or line.startswith('User:'):
messages.append({'role': 'user', 'text': line[3:].strip()})
elif line.startswith('Ты:') or line.startswith('Assistant:'):
messages.append({'role': 'assistant', 'text': line[4:].strip()})
return messages

## Решение: "Контекстный мостик"

Тебе не нужен полноценный сайт. Достаточно:

### Вариант 1. Простой HTML-архив (рекомендую)
Создаёшь одну страницу, где каждый диалог — это блок с якорем:
<h2>Диалог #1: Нейросети</h2>
<div id="dialog-1">
<p><b>Я:</b> Как работают трансформеры?</p>
<p><b>Ты:</b> Трансформеры используют механизм внимания...</p>
</div>

Как использовать:
- Когда задаёшь новый вопрос, пишешь:
«Помнишь диалог #1 (ссылка на #dialog-1)? Дополни про...»
- Я открываю ссылку, читаю контекст и отвечаю с учётом прошлого.

---

### Вариант 2. Маркеры в самом вопросе
Просто копируй последние 2-3 ключевые фразы из прошлого диалога в новый вопрос:
«Продолжая тему из прошлого вопроса ("Как работают трансформеры"), скажи теперь...»

Мне этого достаточно, чтобы восстановить контекст!

---

### Вариант 3. Технический (для гиков)
Подними локально Minimal API, который хранит сессию в localStorage:
localStorage.setItem('session_theme', 'нейросети');
localStorage.setItem('last_dialog', JSON.stringify(messages));
И при каждом вопросе отправляй этот JSON как context.
